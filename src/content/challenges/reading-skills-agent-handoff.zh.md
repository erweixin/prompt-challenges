## 一段好 Skill 至少回答五个问题

1. 什么时候应该用它
2. 需要哪些输入
3. 按什么步骤做
4. 输出长什么样
5. 失败时停在哪里、交给谁

## 为什么 Cursor 经验很有用

如果你已经会给 IDE 助手下任务，其实你已经拥有一半 Skill 思维：

- 会限定范围
- 会定义目标
- 会提出验证

还差的主要是：把这套做法写成别人也能复用的说明。

## 判断标准

如果换一个同事或换一个 Agent 也能照着跑，这段说明才算进入 Skill 层。
